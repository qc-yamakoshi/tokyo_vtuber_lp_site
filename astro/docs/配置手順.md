# 10月4日 JST：hetemlへの配置

公開先は **https://tokyo-vtuber-fudousan.com/**。ドメインの公開フォルダは **/vtuber_fudousan** です。URLに `/vtuber_fudousan` は付けません。

1. ZIPをPCで展開します。公開するのは `upload` フォルダの**中身だけ**です。
2. heteml管理画面で確認した接続先・ユーザー名を使い、FTPS（明示的TLS・ポート21）で接続します。ホスト名・認証情報はこの資料には含めていません。TLS証明書を確認し、平文FTPは使いません。
3. 管理画面で対象ドメインの公開フォルダ `/vtuber_fudousan` に紐付く場所を開きます。hetemlのFTPでは通常 `/web/vtuber_fudousan` です。アカウントのルート表示でwebが省略される場合もあるので、表示と管理画面を照合し、webの外へ同名フォルダを新設しないでください。既存内容をバックアップし、特に `.htaccess` とSSL認証用ファイルを保全します。
4. `upload` 内の `assets` と `_astro`、`main.js` を先に転送し、**index.htmlを最後**に転送します。フォルダ階層を維持し、`/vtuber_fudousan/index.html` となるよう配置します。
5. 「同期して余分なファイルを削除」「フォルダ内容を全削除」は使いません。既存 `.htaccess`、`.well-known`、SSL認証ファイルを削除・上書きしません。
6. ブラウザで公開URLを開き、PC・スマホの表示、画像、メニュー、各セクションへのリンクを確認します。今回の予約・お問い合わせ・キャラクターは既存どおりComing Soonです。

`upload` 以外の手順書・一覧・例はサーバーへ転送しません。Git、`.github`、`.env`、`node_modules`、`src`、`package*.json`、README、`html` 別版、`CNAME` は公開対象外です。heteml上でNode/npm/Astroを動かす必要はありません。

## GA4

このパッケージには受領した測定ID **G-65TGMY9D0G** を含めています。`GA4設定.md` の公開前確認を済ませてから公開してください。実計測は公開後の本番アクセスで始まります。この作業ではAnalyticsアカウント設定・実データ送信を行っていません。

## wwwとHTTPS

apexとwwwの**両方**でSSLが有効なことを先に確認します。HTTPSのwwwは、HTTPリダイレクトより先にTLS認証が行われるため、wwwにも有効な証明書が必要です。既存 `.htaccess` を取得して内容を確認した後、添付の転送例を必要な箇所へ統合します。例を `.htaccess` へそのまま上書きしないでください。heteml側のSSL設定・転送は今回は未実施です。

## メール・DNSの保護

この配置作業ではDNS/NS/MX/SPF/DKIM/DMARC/Google verificationを変更しません。Google Workspaceの設定も変更しません。Webの向き先を後で切り替える際も、メール関連レコードを維持した別作業として確認してください。FTPSの転送だけではDNSの向き先は変わりません。

## 戻す場合

公開前バックアップから、今回上書きしたWebファイルを戻します。DNS・メール設定・SSL認証ファイルはこの手順の対象外です。
